📊 Comparaison : Approche Actuelle vs Proposition Pro

Critère Actuel (avant) Proposition 1 (simple) Proposition Pro (nouvelle)
Navigation desktop Header marketplace isolé, pas de lien vers app Bouton "← Accueil" ajouté Top bar unifiée avec tabs globales
Navigation mobile Bottom nav différente selon les pages Lien "AgroField" dans marketplace Menu hamburger + bottom nav cohérente
Hiérarchie visuelle Éléments éparpillés, pas de focal point Meilleure organisation Hero section + cards + FAB clair
Accès rapide actions Publier caché dans la nav FAB visible FAB flottant + search prominant
Cohérence design 2 systèmes de couleurs différents Harmonisation partielle Design system unifié (tokens shadcn)
Feedback utilisateur Pas d'indications de fraîcheur Quelques badges Badges + timestamps + verified sellers
Cette approche professionnelle inclut :
• Top bar unifiée sur desktop avec navigation globale
• Menu hamburger sur mobile pour accéder à toutes les sections
• Bottom nav simplifiée (5 items max) + FAB pour action principale
• Hero section avec stats clés et search bar prominante
• Badges de statut, timestamps, et indicateurs de confiance
• Design cohérent avec le reste de l'app (tokens shadcn)
